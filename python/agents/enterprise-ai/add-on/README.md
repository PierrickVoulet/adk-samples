# Enterprise AI Google Workspace add-on

Integrates with the *default* Gemini Enterprise AI agent natively.

## Supported Platforms

- **Gmail**: Adds a contextual sidebar to your inbox. When an email is selected, the Add-on extracts its subject and body natively and passes it as context to the Gemini Enterprise AI model, allowing users to ask questions like "Summarize this email" or "Extract the key points" seamlessly.
- **Google Chat**: Adds a chat app integration allowing users to converse directly with the Gemini Enterprise Agent natively within their Workspace messaging DM spaces.
